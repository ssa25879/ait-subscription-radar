# Proposal

## Why

홈·등록·상세 화면에 청록색 기반 디자인이 적용됐지만 일부 상태와 실제 토스 앱에서의 표현은 충분히 확인되지 않았다. 현재 구현을 기준으로 화면 일관성과 접근성을 마무리할 범위와 완료 기준을 정한다.

## What Changes

- 기존 홈 요약·목록, 등록/수정, 상세/삭제 확인 화면의 시각적 위계와 상태 표현을 점검하고 필요한 부분만 일관되게 보완한다.
- 빈 목록, 필터 결과 없음, 로딩, 저장 실패와 삭제 확인에서 안내와 조작을 식별하기 쉽게 유지한다.
- 작은 화면, 긴 이름·큰 금액, 키보드, 터치 영역과 safe area를 브라우저 및 Android에서 확인한다.
- 플랫폼 내비게이션과 상세의 자체 돌아가기 버튼 동시 노출 여부를 확인하고 공식 기준에 맞게 필요한 화면 표현을 조정한다.
- 새 디자인의 검증 결과를 기존 MVP 6단계 기록에 연결한다. 콘솔 앱 정보 제출, 광고 발급, 기능 추가, 등록용 이미지 제작은 범위에서 제외한다.

## Capabilities

### New Capabilities

- `screen-design-consistency`: 기존 구독 관리 화면의 시각적 위계, 상태 표시 및 작은 화면에서의 접근성.

### Modified Capabilities

없음. 현재 주 명세는 비어 있으며 진행 중인 `subscription-radar-mvp`의 요구사항과 충돌하거나 이를 대체하지 않는다.

## Impact

- React 화면 `src/pages/`, `src/App.css`, `src/pages/SubscriptionForm.css`, 필요 시 `apps-in-toss.config.ts`에 국한한다.
- 기존 TDS, SDK, 저장·계산·광고 동작과 데이터 형식을 유지한다.
- `subscription-radar-mvp`의 미완료 6.2~6.5 및 실기기 결과와 중복 없이 연계한다. 새 변경을 적용하려면 별도 요청이 필요하다.
