# 구독레이더 (Subscription Radar)

수동 등록한 구독의 예상 결제일과 예상 지출을 관리하는 앱인토스 WebView 미니앱입니다.
개발 환경·서비스 안내 화면과 날짜/비용 계산·입력 검증·Storage 저장 기반을 구성했습니다. 구독 CRUD 화면, 저장 모듈의 화면 연결, 광고는 아직 구현하지 않았습니다.

## 개발

Node.js 24 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
npm run lint
npm run test -- --run
npm run typecheck
npm run build
```

React 18, TypeScript, Vite, TDS 및 앱인토스 SDK 3.x를 사용합니다. 실제 설치 버전은 package-lock.json에 기록되어 있습니다.
브라우저용 SDK mock 및 AIT 개발 패널은 Vite에 연결되어 있습니다.

## 콘솔 등록 전 설정

apps-in-toss.config.ts의 local-development는 로컬 빌드 전용 임시 appName입니다. 콘솔 등록 후 실제 앱 식별자로 교체해야 합니다.
개발용 슬러그를 콘솔 식별자로 간주하지 않습니다. 현재 번들은 등록·배포용이 아닙니다.
권한은 빈 배열로 시작하며 로그인·서버·광고 ID는 설정하지 않았습니다.

npm run build는 웹 빌드와 .ait 번들을 생성합니다. 콘솔 업로드와 Android 토스 앱 검증은 별도로 진행해야 합니다.
기능 요구사항은 루트의 개발 기획서를, 디자인 지침은 docs/design-guide.md를 참고합니다.

예상일은 KST 달력 날짜와 원래 기준일로 계산합니다. 월말·윤년에는 해당 월 말일로 보정하며 다음 회차에는 원래 일을 복원합니다. 월 환산은 평균 비교값이며 실제 월 청구액이 아닙니다. 원 단위 표시는 활성 금액을 합산한 뒤 한 번 반올림합니다.

## 저장 기반

공식 Storage에 `subscription-radar:data:v1` 키, `schemaVersion: 1` 형식으로 원본 목록과 수정 시각만 저장합니다. 계산 결과는 저장하지 않습니다. 저장 성공 후 확정 목록을 변경하고, 실패하면 기존 목록과 입력을 유지하도록 저장 훅을 제공합니다. 손상 JSON·잘못된 레코드·미지원 스키마는 자동 초기화하거나 덮어쓰지 않고 재시도를 제공합니다.

기록은 해당 기기에 의존합니다. 토스 앱 삭제·기기 변경·일부 저장소 초기화 시 소실될 수 있으며 자동 백업이나 동기화는 없습니다. 현재 저장 모듈은 테스트로 검증했으며 초기 안내 화면에 연결하는 작업은 아직 남아 있습니다.
